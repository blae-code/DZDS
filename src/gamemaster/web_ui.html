📱 In-App Installation Instructions
  • Desktop Chrome / Edge / Brave / Vivaldi: Click Install App above or the ⊕ icon in your browser address bar. Launches in a dedicated chromeless window with full offline support.
  • Apple iOS & iPadOS (Safari): Tap the Share button (↑ square with arrow) at the bottom or top of Safari → choose Add to Home Screen → tap Add. When installed via a shared link, your access token is preserved automatically.
  • Android (Chrome, Edge, Samsung Internet, Firefox): Tap Install App or tap Menu (⋮) → Install app / Add to Home screen.
  • Firefox Desktop: Offline caching is active automatically. For a dedicated desktop window, use the PWAsForFirefox extension or your system WebApp Manager.
💻 Local Server & Host Runbook
  • make dashboard OPEN=1 — Start the local server on http://127.0.0.1:8787 and open your default browser.
  • make dashboard SHARE=1 OPEN=1 (or tools/dashboard.py --share --open) — Start the server, spawn an instant Cloudflare HTTPS tunnel, and print an off-LAN share link.
  • make dashboard PORT=8787 PUBLIC_URL=https://my-host.example — Bind custom port or Tailscale Funnel / reverse proxy address.
  • Offline Mode: The Service Worker pre-caches all operational views, maps, and guides. You can launch your installed PWA and review the world even with no internet connection.
